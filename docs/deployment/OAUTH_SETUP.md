# Google and GitHub OAuth setup

CampusFlow constructs both provider callbacks from `APP_BASE_URL`. The value in
the provider console and the value generated by the running application must be
identical.

## Local Docker service

Set:

```text
APP_BASE_URL=http://localhost:8080
```

GitHub OAuth App:

```text
Homepage URL: http://localhost:8080
Authorization callback URL: http://localhost:8080/login/oauth2/code/github
```

Google OAuth web client:

```text
Authorized JavaScript origin: http://localhost:8080
Authorized redirect URI: http://localhost:8080/login/oauth2/code/google
```

Google Calendar API must be enabled for the Google project. If the consent
screen is in testing mode, add the demonstration Google account as a test user.

## Environment variables

Keep credentials in `.env` locally and in Azure App Settings online:

```text
GITHUB_CLIENT_ID=...
GITHUB_CLIENT_SECRET=...
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
```

Do not commit `.env`. A GitHub personal access token beginning with `ghp_` is
not an OAuth App client secret.

## Verification

The authorization entry points are:

```text
/oauth2/authorization/github
/oauth2/authorization/google
```

After sign-in, the application stores the provider identity, authorized display
name, and avatar URL. GitHub profile/repository and Google Calendar calls are
available only to a session authorized by the corresponding provider.

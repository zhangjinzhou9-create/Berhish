# CampusFlow Classroom Editorial

An extracted-and-refined visual system for the CampusFlow classroom presentation.

The previous frontend established the useful product structure—local conditions, personal profile, and account/OAuth—but presented every area in one dark glass surface. This system keeps those functions and replaces the visual language with a lighter editorial composition.

## Foundation

- Canvas: warm paper `#F2EEE6`
- Ink: soft black `#171613`
- Primary accent: vermilion `#D84A32`
- Secondary accents: moss `#6E7665`, faded blue `#879AA1`
- Display type: Shippori Mincho
- Interface type: Zen Kaku Gothic New
- Technical labels: IBM Plex Mono

## Page personalities

### Today

An opening magazine spread. Weather is the hero number; location search and country facts sit in supporting panels. Red architecture is the focal image.

### Profile

A personal dossier and portfolio spread. The public preview leads; editing is a secondary mode, not the default visual.

### Account

A compact identity/passport page. OAuth providers and connected services are framed as evidence for the classroom demo.

## Image hierarchy

Use one primary image at 100% visual weight, one or two supporting images at 65–80%, and background fragments at 35–55%. Shared filtering prevents a bright image from breaking the composition.

## Responsive target

Design desktop-first for a 1440 × 900 classroom screen. At 900px and below, maintain the editorial reading order while removing overlaps that obscure content.
